# referencias/

Coloque aqui os PDFs das publicações que você estuda (ex.: `lff_TPO.pdf`).
Esta pasta é ignorada pelo git: os arquivos ficam só na sua máquina, porque
são protegidos por direitos autorais. O repositório guarda apenas os dados
extraídos (índice das lições e referências bíblicas) em `dados/livros/`.
